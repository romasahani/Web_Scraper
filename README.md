# Image Web Scraper

A Python-based web scraping application that searches for images based on a user-provided keyword and automatically downloads them to a local directory.
![download](https://github.com/romasahani/Web_Scraper/assets/121279220/aef6f4cf-9ddc-46c8-9bed-ef672b1b0164)

## 📖 Overview

This project is a simple image scraper built with Python. Users enter a search keyword, and the application retrieves and downloads related images from the web automatically.

The project demonstrates the fundamentals of web scraping, HTTP requests, HTML parsing, and file handling using Python.

---

## ✨ Features

- Search images using a keyword
- Automatically download multiple images
- Save images locally
- Simple and easy-to-use interface
- Customizable search queries

---

## 🛠️ Technologies Used

- Python
- Requests
- BeautifulSoup4
- HTML Parsing
- File Handling

## 🚀 Getting Started

### Prerequisites

- Python 3.9 or later

### Installation

```bash
git clone https://github.com/romasahani/Web_Scraper.git

cd Web_Scraper

pip install -r requirements.txt
```

### Run the Application

```bash
python main.py
```
